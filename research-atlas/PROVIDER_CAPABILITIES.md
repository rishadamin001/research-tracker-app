# Provider capabilities

Official documentation checked **2026-11-07**. Provider allowances and features can change.

| --- | --- | --- | --- |
| OpenAlex | Literature discovery, journal lookup by ISSN and open-copy lookup by DOI. Anonymous public API access requires neither an account nor payment details. | OpenAlex documents an anonymous allowance equivalent to $0.10 of usage per day and up to 10 requests per second for ordinary requests. Atlas sends a keyword query with an optional starting year and open-access filter. It starts with 20 records and offers manually requested basic continuation, capped at 5 pages / 100 records. Related reference/citation discovery is separately capped at 20 records. Advanced Boolean operators, parentheses and wildcards are rejected before requesting. | Active by default. Search details show the executed terms, filters, page, reported total, available quota fields and errors. After a quota response, wait for any supplied retry time or follow the public Crossref search link. ## Search history and coverage

The project audit trail retains original and executed query, filters, provider/default relevance, Atlas parser version, each successful or failed page attempt, timestamps, returned/reported counts, result IDs, errors and readable quota fields. JSON preserves the full run; CSV summarizes it with formula-prefix neutralization. Project logs travel with backups. Standalone search stores the latest 50 run records locally, offers exports and a clear-history action, and does not add those records to project backups.

Atlas distinguishes the provider-reported match total from records actually retrieved. The app uses documented basic paging; deep cursor continuation remains unconfigured because it requires a verified API key. No account, key or balance is added. Basic paging is not a stable snapshot: relevance can change between pages, and repeated display IDs are deduplicated. Ranking applies only to retrieved records; exhaustive review coverage is not claimed. [Paging](https://help.openalex.org/api/paging/) · [Implementation detail](docs/SEARCH-CONTINUATION.md)

Manual Refresh compares the first retrieved page against the last successful matching query/filter snapshot. A new-to-snapshot record may be an older publication. No background monitoring or persistent full-result cache runs. Related-paper suggestions are separate from saved-library links and need reading/screening before becoming evidence.

The browser search has a 15-second request deadline. It does not retry automatically. When the browser can read `Retry-After`, Atlas pauses further searches in that session until the indicated time. A known exhausted allowance with a readable reset time also blocks new search and related-paper requests until reset. Available usage headers are stored with the search. Cross-origin restrictions or a configured gateway can make headers unavailable. Atlas never switches to a paid search mode on failure. [OpenAlex error handling](https://help.openalex.org/api/errors/)

## Publication costs and conferences

Atlas separates reading access from the journal’s author-facing open-access list fee. Prices stay unavailable when the provider does not supply a supported amount. New lookup estimates retain a retrieval timestamp and source URL; older imported estimates can lack that date. Comparable listed charges sort using supplied USD values. [Pricing fields and caveats](docs/PUBLICATION-COSTS.md)

Conference cards retain source links and checked dates. Opening a listing leaves Atlas for the corresponding external site.
