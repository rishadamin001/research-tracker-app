# Provider capabilities

Official documentation checked **2026-11-07**. Provider allowances and features can change.

| Provider | Purpose and access | Limits and supported query | Atlas status and fallback |
| --- | --- | --- | --- |
| OpenAlex | Literature discovery, journal lookup by ISSN and open-copy lookup by DOI. Anonymous public API access requires neither an account nor payment details. | OpenAlex documents an anonymous allowance equivalent to $0.10 of usage per day and up to 10 requests per second for ordinary requests. Atlas sends a keyword query with an optional starting year and open-access filter. It retrieves a single page of up to 20 records. Advanced Boolean operators, parentheses and wildcards are rejected before requesting. | Active by default. Search details show the executed terms, filters, page, reported total, available quota fields and errors. After a quota response, wait for any supplied retry time or follow the public Crossref search link. [Authentication and limits](https://help.openalex.org/api/authentication/) · [Usage examples](https://help.openalex.org/access/example-costs/) · [Search syntax](https://help.openalex.org/api/searching/) · [Terms](https://openalex.org/OpenAlex_termsofservice.pdf) |
| Crossref | DOI metadata, publisher and container details, ISSN and updates where deposited. The public REST API requires neither registration nor payment. | Atlas sends one normalized DOI per lookup. Crossref documents 5 requests per second for single-record lookups in the public pool and exposes rate limits in response headers. Atlas does not paginate Crossref metadata. | Active by default. Follow the DOI to the publisher if metadata are incomplete. Crossref metadata do not certify a journal, indexing, retraction status or APC. [REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) · [Access and authentication](https://www.crossref.org/documentation/retrieve-metadata/rest-api/access-and-authentication/) · [Current request limits](https://community.crossref.org/t/refining-rest-api-limits-for-improved-stability-and-reliability/16137) |
| Unpaywall | Optional DOI-to-open-copy lookup through an operator-configured gateway. The public endpoint is free and requires an operator email. | Unpaywall asks users to limit traffic to 100,000 requests per day. Default Pages resolves open copies using OpenAlex. The app does not collect a researcher email for Unpaywall. [Unpaywall REST API](https://unpaywall.org/api) |
| POSI | Bundled journal-level citation quartiles matched by ISSN. No account, payment details or live query to POSI are needed. | Coverage depends on the edition and matching journal identity. ## Search history and coverage

The project audit trail records each completed or failed provider attempt. Each entry retains the submitted query and the exact terms and filters sent, first-page request and result counts, times, a provider request ID when available, and the documentation review date. Older backups keep their original history entries. A standalone search with no selected project shows the current details on screen.

Atlas presents the provider-reported match total separately from records actually retrieved. A first page is useful for exploration and has limited coverage. Deep cursor paging is deferred. OpenAlex documents that cursor continuation requires a verified API key and that its free verified tier currently gives an allowance equivalent to $1/day without a payment method. This release creates no account or key. [Paging](https://help.openalex.org/api/paging/) · [Pricing](https://help.openalex.org/access/pricing/)

The browser search has a 15-second request deadline. It does not retry automatically. When the browser can read `Retry-After`, Atlas pauses further searches in that session until the indicated time. Available usage headers are stored with the search. Cross-origin restrictions or a configured gateway can make headers unavailable. Atlas never switches to a paid search mode on failure. [OpenAlex error handling](https://help.openalex.org/api/errors/)

## Publication costs and conferences

Atlas separates reading access from the journal’s author-facing open-access list fee. Prices stay unavailable when the provider does not supply a supported amount. Comparable listed charges sort using supplied USD values. [Pricing fields and caveats](docs/PUBLICATION-COSTS.md)

Conference cards retain source links and checked dates. Opening a listing leaves Atlas for the corresponding external site.
