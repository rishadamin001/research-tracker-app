# Consolidated review update

- **Reliability.** The original WebKit trace showed the earlier saved indicator remained visible during the question-fill action. Guided step focus previously ran in a later animation frame. Focus now settles as the step renders, question fields read the same project draft in both modes, and the draft indicator reports confirmed storage. Tests check focus, save acknowledgment, reload and failure recovery.
- **Researcher control.** The Notebook links personal interpretations and next actions to saved sources and displays located findings from Evidence Desk. Earlier text remains under its original meaning. Notebook entries travel in a portable backup and can be exported as plain text.
- **Learn.** Six lessons pair worked examples and choice-specific feedback with an explanation and a project task. Revisit dates and explanations are stored in the current browser.
- **Reference exchange.** Select records for RIS or BibTeX transfer and preview exact and possible matches before adding records. Download a project backup to transfer project judgments, evidence, writing and notes.
- **Release boundary.** The website remains a free beta. The [three-query relevance pilot](DISCOVERY-PILOT-010.md) gives a baseline for specific topics. A larger, independently judged comparison should guide changes to ranking. The proposed uncoached beginner study, independent academic review, physical Android and manual assistive-technology testing require participants and devices. Play packaging and account-based integrations are separate follow-on work.

The app checks run independently of the live provider workflow. The latter preserves Crossref diagnostics and the same live searches, so its results show the state of those services during each run.
