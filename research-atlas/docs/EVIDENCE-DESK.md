# Evidence Desk, readiness and Research Passport

The default Literature and Evidence workspace keeps one source selected while the researcher reads, screens and records evidence. The source list and comparison view mount up to 20 records per page. Quartile/source edition, citation count, publisher identity and existing ranking/date/cost ordering remain available. A missing abstract, author, venue, price or source link stays explicitly unavailable. Supplied OpenAlex abstract text is source metadata, not an AI summary or a replacement for full-text reading.

Step-by-step guidance presents Inspect source → Screen → Record evidence as separate tasks. Focus workspace exposes those groups directly. Both use the same project reference records. Mode changes preserve notes, decisions and an open claim form. An unsaved claim must be saved or cancelled before selecting another source or following a writing handoff. Other working-note and screening-draft fields continue to autosave locally.

Include, Maybe and Exclude actions require a recorded reason and append the existing dated screening history. Full-text versus title/abstract stage, reviewer and the criterion as applied remain inspectable after criteria are retired. Evidence entries separate the source claim, exact location, author interpretation, uncertainty and review status. No claim is automatically treated as verified. Source-specific writing links retain the paper/claim identifiers; an ambiguous or missing source identifier is flagged rather than silently choosing another record. Legacy duplicate-ID records can still be edited independently by their project position.

The Desk does not retrieve paywalled text, upload manuscripts or create a PDF reader. Legal source/open-copy links remain external. Supplied abstracts do not establish permission or access to the full article. Exports include all saved records, including exclusions and reasons. The comparison table is a view over the same notes and located claims rather than a separate store.

## Readiness review

Project Overview supplies a deterministic completeness review: intentional question versus draft, scope/objectives, pathway, unresolved screening, missing source identity, reviewed located findings, methods/ethics records, data-plan items, writing-support prompts, venue records and upstream review flags. Findings are review prompts and never block early exploration. They do not certify design suitability, ethics approval, novelty, journal legitimacy or scientific quality. No academic-quality percentage is computed.

## Research Passport

Markdown and JSON passport exports include question versions, actual search queries/filters/dates, source-selection criteria and history, located claims with uncertainty, methods and data planning, decisions and the bounded activity trail. JSON also retains the structured writing and publication records. Passport Markdown is a human-readable provenance narrative, while manuscript exports remain in Writing Studio.

The passport can contain unpublished drafts and private notes. Review it before sharing. It is not a restore backup: use the existing portable project-backup export for recovery. History is local, bounded, editable through imports and not tamper-proof; missing earlier activity cannot be reconstructed. Old project schemas and portable backups continue to use additive fields and the existing migration behavior.

Tests cover location-based readiness, metadata-only limitations, missing/duplicate identity, source-specific note updates, exported provenance and unsupported writing prompts. The release testing document records completed browser and live checks; test definitions alone are not verification.
