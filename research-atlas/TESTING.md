# Verification

## Release checks

Version 0.6.0 local checks passed: `npm run typecheck`, `npm run lint`, `npm test` (42 tests), `npm run build`, and `npm audit --omit=dev` (zero known production vulnerabilities). The focused final run passed 48 browser cases across desktop Chromium, Pixel 7 emulation and WebKit: eleven public-route axe scans per browser, v2 integrity/legacy imports, beginner setup, duplicate merge/undo and dark 320 CSS-pixel reflow. Earlier runs exposed a primer contrast defect and hidden mobile save status; both were fixed and the affected checks rerun. Firefox could not launch in the Windows environment (`spawn UNKNOWN`); its Linux CI verification is tracked in [the 0.6.0 workflow](https://github.com/rishadamin001/research-tracker-app/actions/runs/42366621776).

The [full 0.6.0 CI run](https://github.com/rishadamin001/research-tracker-app/actions/runs/42366621776) passed typecheck, lint, all 42 unit tests, the production build, and all 148 browser cases across desktop Chromium, Pixel 7 emulation, Firefox and WebKit. Its checked source revision is `55c9498c7fe37496a9e87b151228ee94fd886c32`. This includes eleven separate public-route axe scans in each browser target, with zero reported violations under the configured WCAG A/AA tags. Automated success does not establish full accessibility conformance.

Version 0.5.0 passed typecheck, lint, build, 22 unit tests, and 57 browser cases across desktop Chromium, Pixel 7 emulation, and desktop Firefox. The [GitHub Actions run](https://github.com/rishadamin001/research-tracker-app/actions/runs/42298941038) checked the deployed revision `4e2d19789dfcde741032e66dd7c8bd5cf2e11991`.

Run `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, and `npm run test:e2e`. Use `npx playwright install chromium firefox webkit` to install the browser binaries. The default suite uses desktop Chromium and Pixel 7 emulation. Set `ATLAS_FIREFOX=1` and `ATLAS_WEBKIT=1` to include the other engines. CI enables both.

Fixtures cover literature sorting, fee provenance, rate limits, screening history, claim export, reference import, backup validation, write failure recovery, and planner persistence. New fixtures cover bounded page continuation, quota resets, page failure history, related-work requests, merge limits and history collisions, methods abstention, structured DMP exports and backup v2 corruption. Accessibility cases scan all eleven public top-level views with axe-core. Keyboard focus is checked separately. The 320 CSS-pixel test is a reflow-width check, not physical zoom or assistive-technology testing. Physical devices and a complete manual screen-reader/accessibility audit remain outside this suite.
