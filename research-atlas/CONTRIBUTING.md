# Contributing

Use Node 24, npm lockfile, strict TypeScript, semantic accessible controls, and reviewed source links. Do not introduce paid runtime dependencies. Keep domain data outside UI routing. Add behavior-focused tests for data safety, provider changes, and critical user flows.

Run typecheck, lint, unit tests, build, and desktop/mobile E2E. Fixture tests do not prove live provider availability. Never commit credentials, real research records, or generated node_modules/.next output. Maintain the coverage and limitation register when expanding scope.
