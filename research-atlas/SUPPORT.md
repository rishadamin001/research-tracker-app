# Support and recovery

Public page: [Support & recovery](https://rishadamin001.github.io/research-tracker-app/#support). Updated 7 November 2026.

Use the [public issue tracker](https://github.com/rishadamin001/research-tracker-app/issues) for bugs and general questions. Include browser/device, affected screen, steps, expected result, and an invented example. Do not post participant data, private backups, credentials, unpublished manuscripts, or identifying information. A private support email has not been configured, and response times are not guaranteed.

If projects are missing, check the exact website address, browser, and browser profile. Browser data is separated by origin; localhost, GitHub Pages, and another domain cannot directly read one another's projects. Return to the old address to export before changing domains. Import at the destination with My projects, review the manifest and counts, and import as new copies. See [migration instructions](docs/BACKUP-MIGRATION.md).

If saving fails, keep the tab open and download the recovery backup before reloading. The maintainer has no central project copy to recover after browser data is cleared. Keep backups private and manage downloaded copies separately.
